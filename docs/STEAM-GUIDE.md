# Need for Speed Hot Pursuit 2 (2002) — широкий экран, 240 Гц и MSAA

Мод для PC-версии Hot Pursuit 2 центрирует заставки, исправляет положение очков, плавно отрисовывает машины и камеру на мониторах с высокой частотой и позволяет включить счётчик кадров. Игра использует доступную для текущего разрешения частоту; на 1920×1080 подтверждены 240 Гц. Физика сохраняет исходный темп.

## Установка

1. Подготовьте рабочую копию PC-игры 1.32.20-R (242) с установленными Ultimate ASI Loader x86, d3d8to9 и HP2WSFix.
2. Скачайте архив мода в GitHub Releases. Скопируйте два файла из его папки `scripts` в `scripts` игры. Если файлы уже существуют, сохраните их для отката.
3. Примените комплектный патч HP2WSFix. Он рассчитан на конкретный исходный ASI. Сверьте контрольную сумму по руководству установки из ZIP.
4. Запустите игру и пройдите до одиночной гонки. В папке `scripts` появится `HP2Display.log`. Строка с `actual=...` показывает фактический режим.

## Настройки

В `scripts/HP2Display.ini` оставьте `MaxRefreshHz=Auto` для автовыбора или задайте верхнюю границу в герцах. `MSAA=4` — начальное сглаживание. Попробуйте `2`, если нужны дополнительные кадры в секунду, или `8`, если видеокарта справляется. `ShowFPS=0` скрывает счётчик, `Camera=0` отключает интерполяцию. Перезапустите игру после изменения файла.

## Откат

Закройте игру, уберите установленные файлы HP2Display из `scripts` и верните сохранённые файлы. Для возврата к исходному HP2WSFix скопируйте сохранённый оригинал поверх исправленного ASI. Полный порядок установки, точные контрольные суммы и документация по настройкам входят в ZIP.

Широкоформатный модуль основан на работе xan1242. [Оригинальный HP2WSFix](https://github.com/xan1242/hp2wsfix)
