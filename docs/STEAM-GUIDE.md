# Need for Speed Hot Pursuit 2 (2002) — широкий экран, 240 Гц и MSAA

Мод для PC-версии Hot Pursuit 2 центрирует заставки, убирает цветную полосу у логотипа EA, исправляет положение очков, плавно отрисовывает машины и камеру на мониторах с высокой частотой и позволяет включить счётчик кадров. Игра использует доступную для текущего разрешения частоту. На 1920×1080 подтверждены 240 Гц. Физика сохраняет исходный темп.

## Установка

1. Подготовьте рабочую копию PC-игры 1.32.20-R (242).
2. Скачайте игровой ZIP с единым HP2Display из GitHub Releases. Сохраните файлы для отката. При обновлении с v0.2.0 перенесите отдельный `HP2WSFix.asi` в резервную копию за пределами папки игры.
3. Скопируйте `d3d8.dll` и `global.ini` рядом с `NFSHP2.exe`, а файлы из `scripts` архива — в `scripts` игры. Перенесите свой `SaveDir` из старого HP2WSFix.ini, если вы его меняли. Если уже используете свой `global.ini`, сверяйтесь с руководством в ZIP.
4. Запустите игру и пройдите до одиночной гонки. В папке `scripts` появится `HP2Display.log`. Надпись `HP2WSFix: integrated` подтверждает загрузку встроенного модуля, а строка с `actual=...` показывает фактический видеорежим.

## Настройки

В `scripts/HP2WSFix.ini` режим `Resolution=Desktop` использует текущее разрешение основного монитора. Для ручной настройки выберите `Resolution=Config` и укажите размеры в `rendercaps.ini`. Положение очков и других элементов HUD можно настроить в `[HUDOffset]`.

В `scripts/HP2Display.ini` оставьте `MaxRefreshHz=Auto` для автовыбора или задайте верхнюю границу в герцах. По умолчанию `MSAA=8`. Если нужны дополнительные кадры в секунду, попробуйте `4` или `2`. `ShowFPS=0` скрывает счётчик, `Camera=0` отключает интерполяцию. Перезапустите игру после изменения файла.

Для отражений кузова доступны `ReflectionSize=256`, `512` или `1024`. Значение `0` сохраняет штатные отражения. `FrameLimit=0` оставляет программный лимит FPS выключенным.

## Откат

Закройте игру, верните сохранённые версии ASI, конфигов и загрузчика. Если автоматическое разрешение перезаписало ваши размеры, восстановите прежний `rendercaps.ini`. Полный порядок установки и отката входит в ZIP.
