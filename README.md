# Need For Speed Hot Pursuit 2 Display Mod

Мод для PC-версии Need for Speed: Hot Pursuit 2 (2002). Поддерживает широкоформатные заставки, автоматический выбор частоты монитора, интерполяцию камеры и машин, счётчик FPS и MSAA.

Программирование и тестирование выполнял Codex OpenAI.

Для игры нужен собственный экземпляр NFSHP2 x86, версия 1.32.20-R (242), и совместимые Ultimate ASI Loader x86 и d3d8to9. Точная подпись проверенного EXE, установка и откат описаны в [руководстве игрока](docs/INSTALL.md).
