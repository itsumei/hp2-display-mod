# Need For Speed Hot Pursuit 2 Display Mod Fix and Improvements

**HP2Display** — основной мод этого проекта для PC-версии Need for Speed: Hot Pursuit 2 (2002). Он адаптирует отрисовку игры к современным дисплеям, добавляет сглаживание и делает движение камеры и машин плавнее при высокой частоте кадров.

Программирование и тестирование выполнял Codex OpenAI.

## Что добавляет HP2Display

- **Автовыбор частоты и VSync.** HP2Display запрашивает наибольшую доступную частоту для текущего полноэкранного разрешения. Если драйвер отклоняет режим, плагин пробует другие варианты. Фактическая частота записывается в журнал. На сборке v0.2.0 подтверждён режим **1920×1080 при 240 Гц**.
- **Интерполяция в гонке.** Камера, машина игрока и соперники интерполируются синхронно между шагами симуляции. Физика сохраняет исходный темп около 60 тиков в секунду.
- **Сглаживание MSAA.** По умолчанию мод запрашивает **8×**. Если режим недоступен, он пробует 4× и 2×. Фактическая кратность записывается в журнал.
- **Широкоформатные заставки.** Видеологотип и вступительный ролик центрируются и вписываются в экран с сохранением пропорций. В v0.3.0-rc.2 исправлена тонкая зелёная полоса справа у логотипа.
- **Счётчик FPS и диагностика.** Счётчик показывает частоту отрисовки игры. Для разбора микрорывков можно включить периодическую статистику или покадровую запись в CSV.
- **В тестовой версии v0.3.0-rc.1** HP2Display включает HP2WSFix 2.5, синхронизирует отрисовку при смене ракурса и добавляет программный лимит FPS и настраиваемые отражения кузовов с исправлением зеркала заднего вида.

### Настройки HP2Display

Откройте `scripts/HP2Display.ini` и перезапустите игру после правок.

| Параметр | По умолчанию | Что меняет |
| --- | --- | --- |
| `[Display] MaxRefreshHz` | `Auto` | Число задаёт верхний предел в Гц, например `144` или `240`. Значение `0` оставляет выбор игре. |
| `[Display] VSync` | `1` | `1` включает вертикальную синхронизацию в полноэкранном режиме, `0` выключает, `-1` сохраняет выбор игры. |
| `[Display] FrameLimit` | `0` | Программный лимит FPS в v0.3.0-rc.1. `0` выключает его. |
| `[Graphics] MSAA` | `8` | Выбирает 2×, 4× или 8×. Значение `0` сохраняет настройки игры. |
| `[Graphics] ReflectionSize` | `0` | В v0.3.0-rc.1 доступны `256`, `512` и `1024`. `0` оставляет штатные 128×128. |
| `[Interpolation] Camera` | `1` | Значение `0` отключает интерполяцию камеры и машин. |
| `[Overlay] ShowFPS` | `1` | Значение `0` скрывает счётчик. |

Фактический видеорежим и кратность MSAA можно проверить в `scripts/HP2Display.log`. Описание покадрового замера и инструкции для разработчиков находятся в документации. [Диагностика](docs/TESTING.md) · [Архитектура HP2Display](docs/ENGINE.md)

## HP2WSFix и загрузчик

Доработанный **HP2WSFix 2.5** отвечает за разрешение и расположение HUD. По умолчанию он берёт текущее разрешение основного монитора. Режим `Resolution=Config` позволяет задать размеры вручную, а секция `[HUDOffset]` управляет отступами элементов HUD. Ultimate ASI Loader в `d3d8.dll` загружает ASI и предоставляет слой d3d8to9.

Благодарю **xan1242 (Xanvier)** за создание и развитие HP2WSFix.

[Репозиторий HP2WSFix](https://github.com/xan1242/hp2wsfix) · [Релизы](https://github.com/xan1242/hp2wsfix/releases) · [Лицензия MIT](https://github.com/xan1242/hp2wsfix/blob/2.5/LICENSE)

## Установка и документация

Для игры нужен собственный экземпляр NFSHP2 x86 версии 1.32.20-R (242). Тестовый комплект `HP2Mod-v0.3.0-rc.2-win32.zip` содержит единый ASI, загрузчик и конфиги. При обновлении с v0.2.0 сохраните копию отдельного `HP2WSFix.asi` за пределами папки игры. [Руководство по установке и откату](docs/INSTALL.md)

Для установки **v0.2.0** закройте игру, сохраните копии заменяемых файлов и распакуйте игровой ZIP. Положите `d3d8.dll` и `global.ini` рядом с `NFSHP2.exe`, а содержимое папки `scripts` из ZIP — в `scripts` игры. Если у вас настроен свой `global.ini`, перенесите параметры загрузчика по инструкции. [Релиз v0.2.0](https://github.com/itsumei/hp2-display-mod/releases/tag/v0.2.0)
