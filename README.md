# Need For Speed Hot Pursuit 2 Display Mod Fix and Improvements

Мод для PC-версии Need for Speed: Hot Pursuit 2 (2002). Поддерживает широкоформатные заставки, автоматический выбор частоты монитора, интерполяцию камеры и машин, счётчик FPS и MSAA.

Программирование и тестирование выполнял Codex OpenAI.

Для игры нужен собственный экземпляр NFSHP2 x86 версии 1.32.20-R (242). В готовый комплект входят HP2Display, доработанный HP2WSFix 2.5 и загрузчик `d3d8.dll` с d3d8to9. По умолчанию игра берёт текущее разрешение основного монитора. Режим `Config` позволяет задать размеры вручную, а секция `[HUDOffset]` управляет положением элементов HUD. Порядок установки и отката описан в [руководстве игрока](docs/INSTALL.md).
